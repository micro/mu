# About

**Work with Agents.** Make one, give it an address, hand it a job. It picks the
work up while you are elsewhere and answers on the conversation you asked in —
here, or wherever you wrote from. It has tools, it keeps the thread, and it
remembers what you told it last time.

## Agents

You make an agent: a name, a standing instruction, and the services it may use.
It gets its own address. You chat with it here, or write to it from anywhere,
and a token lets Claude, Cursor or your own code use the tools you gave it.

## The inbox

Every conversation this account has had with an agent, on whichever client it
arrived, kept in one record and read in one place. A new channel joins that
record rather than starting a second one.

## Tools and services

An agent that can be written to and cannot do anything is a chatbot with an
address. Behind these is the everyday internet: news, mail, search, weather,
markets, video, places, files and notes.

[Tools](/tools) is what an agent can call. [Services](/services) is the same
catalogue as things you can open yourself. Both are generated from what this
instance actually runs, so neither can drift from it.

## Paying

Most of it is free. Storage, and any read that only touches this instance, costs
nothing. What costs anything costs it because a model ran or a paid provider
answered, and the price list is [/tools](/tools).

A person tops up with a card and priced calls come out of that balance. An agent
pays per request in USDC over [x402](https://x402.org) and never signs up at
all — the payment is the identity.

Self-hosting, neither is switched on: an instance with no Stripe keys and no
x402 address cannot charge anybody, so every tool is simply free.
